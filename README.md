# Campus Market

**Campus Market** - это Торговая площадка в рамках
определенного учебного заведения где можно удобно продавать, дарить
или обмениваться вещами


## О проекте

В этом приложении можно выставлять вещи на продажу как 
объявление выставив цену или же выбрать категорию обмена, 
чтобы пользователи могли видеть его на главной странице для последующей покупки

## Известные ограничения

1. Два админа, понижающие друг друга одновременно, могут оставить систему без админа.
2. Снятое владельцем объявление (unpublished) модератор скрыть не может.
3. Единственность заявки completed у объявления обеспечивает код, а не БД.
4. Выход из системы делается на клиенте: токен просто удаляется (JWT без состояния).
5. Параллельные cancel и complete не защищены на уровне БД.
6. Нет защиты от подбора пароля (ограничения частоты запросов).
7. Проверка типа изображения проводится с помощью самописной функции которая проверяет только начала байтов файл(не стал юзать Pillow)

## Запуск

### 1. Клонирование репозитория

Перед выполнением команды убедитесь в том что путь консоли находится в нужной папке или же на рабочем столе


```bash
    git clone https://github.com/Chochopay/campusmarket
```
```bash
    cd campusmarket
```
### 2. Установка .env


**Windows**
```bash
    Copy-Item env.example .env
```
**Linux / macOS**
```bash
    cp .env.example .env
```
### 3. Сборка Docker образов и запуск контейнеров

#### Первый запуск

Установите если он у вас не установлен и запустите [**Docker Desktop**](https://www.docker.com/products/docker-desktop/)

Если у вас **Windows**, то прежде установите **WSL 2** через
**PowerShell** от имени администратора

```powershell
    wsl --install
```
Проверьте установилась ли она 
```powershell
    wsl --version
```

Далее в терминале папки проекта запустите проект

```bash
    docker compose up --build
```


После того как докер закончит сборку
откройте проект по ссылке [http://localhost:8000/docs](http://localhost:8000/docs)
